# Авито Очередь

MVP сервиса пользовательской очереди на дефицитные товары.
Пользователь встаёт в очередь перед чекаутом, получает временное персональное
право на покупку, и система гарантирует, что одна единица товара не уйдёт
двум покупателям одновременно
